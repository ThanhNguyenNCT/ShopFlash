# Module storage (frontend)

Nghiệp vụ, dữ liệu và API của module: xem `backend/src/main/java/com/shopflash/modules/storage/AGENTS.md`.

## Màn hình

- Admin: quản lý danh mục, quản lý sản phẩm.

## Giao diện

Dùng design system ở `src/shared/design-system` (không viết mã màu cố định): `PriceTag` (cột giá trong bảng sản phẩm admin). Còn lại dùng Table, Form, Modal của Ant Design.
