# Module storage

Chủ đề: Data storage & management.

## Chức năng

- F1 Quản lý danh mục
- F2 Quản lý sản phẩm

## Thiết kế

Người phụ trách module tự chốt và ghi vào đây khi đã quyết định:

- Dữ liệu: bảng Oracle, key Redis.
- API công khai cho module khác (nếu có).
- Phụ thuộc vào module khác (nếu có).
